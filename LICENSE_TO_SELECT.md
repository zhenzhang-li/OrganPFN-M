# License decision required before public release

No software license has been assigned automatically because the copyright
holder and institutional release terms are not known. Before making the GitHub
repository public, the study team and institution should select an appropriate
license and add it as `LICENSE`.

Common choices include BSD-3-Clause or Apache-2.0 for permissive reuse, but this
is a legal and institutional decision. The UK Biobank data licence does not
authorize redistribution of participant-level data, and a code license must
not be interpreted as permission to redistribute UK Biobank data or third-party
TabPFN checkpoints.
