# Output guide

## Self-supervision

Each threshold directory contains stage checkpoints, a final SSL checkpoint,
step-level losses, epoch summaries, and a training log. Linear-probe MAE is a
periodic representation-quality check and is distinct from the self-supervised
training loss.

## Fine-tuning

Each threshold has five fold directories. Fold assignments and asymmetric-loss
age anchors are stored at the threshold root. Per-fold model files and
validation predictions are generated by the core trainer. Downstream analyses
should state the exact threshold and fold; the study's applied checkpoint is
threshold 30, fold 4, initialized from SSL threshold 90.

## PIOAA

`observed_organs`, `total_deviation`, `magnitude`, `common_level`,
`asynchrony`, `s_magnitude`, and `s_asynchrony` are written per participant.
Scores may be missing when fewer than two organs are observed or the healthy
reference does not contain enough people with the same panel size.

## Cascade

Edge files retain raw effect, P value, FDR-adjusted Q value, eligible sample or
event count, edge type, negative-control floor, and within-type strength.
Route files report reachability, joint strength, hop count, and node sequence.
Loop files report the complete directed cycle and product strength. Do not
interpret strength as a probability.
